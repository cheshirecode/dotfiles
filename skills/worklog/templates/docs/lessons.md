# Worklog lessons

This is a starter template for the data repo's cross-task lessons. Add lessons
from that repo's own work; do not copy task history from the tooling repository.

Keep an entry only when it changes a future decision across tasks. Record a short
lesson, its rationale, and a reference to the task or commit that supports it.
Single-task findings belong in that task's body. Refine or supersede entries as
understanding changes; Git preserves their history.

Architectural decisions belong in maintained design or decision documents. Run
logs, audit snapshots, and handovers belong in Worklog task records.

## Lessons

Add supported, reusable lessons here as work produces them.
